What this checks

Strict JSON syntax and shared Formly configuration rules, including nested fields, common properties, and likely misspellings. Custom field types and properties are allowed.

Component registration, UI-specific properties, expressions, and runtime behavior are not verified. This tool never executes your configuration and does not validate model values. See field properties and model validation.
