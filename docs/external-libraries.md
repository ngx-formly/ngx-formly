# External libraries

Explore community libraries and tools built on top of ngx-formly, or share your own project.
These projects are maintained by their authors. See each project's documentation for installation,
supported Angular and Formly versions, and license terms.

| Type | Name | Description | Demo link |
| --- | --- | --- | --- |
| Builder | [ngx-formly Builder](https://github.com/ngx-formly/ngx-formly-builder) | Shared community form builder with drag-and-drop editing, custom components, live previews, and Formly JSON export. | |

## Share your library

To add a library or tool built on top of ngx-formly, [edit this guide on GitHub](https://github.com/ngx-formly/ngx-formly/edit/main/docs/external-libraries.md)
and open a pull request.

Include the project's type, its name linked to the repository, a short description of what it adds
to ngx-formly, and a link labeled "Demo" if available. Keep entries in alphabetical order by name.
You can also submit corrections or remove an outdated entry through a pull request.
