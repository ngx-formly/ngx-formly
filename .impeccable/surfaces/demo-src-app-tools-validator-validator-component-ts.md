# Formly JSON validator

Mode: Operate. Developers paste a JSON fields array and locate configuration mistakes. This extends the established documentation website.

## Direction contract

THESIS: Connect each diagnostic to the exact source text that needs attention.

OWN-WORLD: Preserve the existing Formly rail, section sidebar, typography, magenta accents, and light/dark CSS variables.

STORY: Open Tools, paste fields, read the validation result, and select a diagnostic to edit its source. The builder remains an external link.

FIRST VIEWPORT: A compact heading and scope explanation sit above a wide JSON editor and narrower diagnostics panel. Small screens stack editor and diagnostics. The empty editor explains the expected array shape.

FORM: User-approved code-led extension. The signature interaction selects and scrolls to a diagnostic's source range. No new visual identity or generated imagery.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
