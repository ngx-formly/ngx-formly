## Users

Angular developers evaluating, learning, and using Formly, as recorded in the existing project context and supported by the README and example application.

## Product Purpose

Formly generates forms from configuration on top of Angular Reactive Forms. Its website helps developers install the library, understand its APIs, and explore runnable examples.

## Capabilities and Constraints

- The website is the existing Angular application under `demo/`.
- Formly supports field configuration, JSON Schema, validation, expressions, custom field types, wrappers, and several UI adapters.
- The user confirmed that the redesign covers the entire documentation website: homepage, shared navigation, guides, and example viewers. Preserve routes and example behavior, including each UI adapter's native controls.
- Keep the README's technical details, compatibility table, learning resources, and contributor credits accessible.
- Product claims come from `README.md`, `docs/`, and working examples. Do not invent adoption or performance statistics.

## Brand Commitments

Keep the Formly name and logo. The user selected https://angular.dev/ as the visual reference for this update.

## Product Principles

- Demonstrate configuration-driven forms with working Formly code.
